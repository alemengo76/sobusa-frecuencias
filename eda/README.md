# Análisis exploratorio de SOBUSA

Estas ediciones públicas reutilizan procedimientos de los EDA existentes con datos ficticios identificados. Abra los cuadernos con el kernel del worker descrito en la [guía de inferencia](../README_INFERENCIA.md). El EDA usa pandas y Matplotlib y se ejecuta sin los modelos ni los datos privados.

| Cuaderno | Procedimiento conservado |
| --- | --- |
| [EDA general](EDA_general.ipynb) | Conteos faltantes por periodo y su denominador, de `EDA_Sobusa.ipynb`. |
| [Ruta 16](EDA_ruta16.ipynb) | Distribución de estados por periodo, estadísticos e histograma, de `EDA_ruta16.ipynb`. |
| [Ruta 21](EDA_ruta21.ipynb) | Ausencias por estado de programación, de `SOBUSA_RUTA_21.ipynb`. |

Las visualizaciones se generan al ejecutar las celdas. Las versiones íntegras con extracciones, salidas ejecutadas, tabulados empresariales, figuras con datos observados y documentación interna se conservan en privado. Los ejemplos de esta carpeta no representan resultados históricos.
